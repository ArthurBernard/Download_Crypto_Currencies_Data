Jobs format

Add entries to the jobs array:

{
  "exchange": "binance",
  "pairs": ["BTC/USDT"],
  "data_type": "ohlc",
  "span": 3600,
  "trigger_kind": "interval",
  "every": 3600,
  "start": "last"
}

stream job:

{
  "exchange": "binance",
  "pairs": ["BTC/USDT"],
  "data_type": "trades",
  "operation": "stream",
  "trigger_kind": "supervised"
}

data_type values:

  • ohlc — requires span in seconds
  • trades
  • orderbook

Exchanges:

binance coinbase kraken bybit okx bitfinex bitmex
